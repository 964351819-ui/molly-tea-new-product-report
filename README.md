# 茉莉奶白·新品数据报表

支持 CSV、XLSX、XLS 商品数据，生成整体报表、可用的子公司维度及汇报总结。支持三平台独立复购汇总和商品清洗。

## 使用方式

子公司识别内置《子公司匹配.xlsx》的省份对应关系。源数据含“省份”（也支持省、门店省份、所在省份、所属省份）时，优先按该对应关系归属子公司，兼容省份简称。没有对应关系时保留有效的子公司/三级机构字段；仍无法识别的记录保留在“未匹配子公司”，不丢弃销量和金额。云南省在匹配表中为 #N/A，因此不会自动分配到其他子公司。门店数仍使用左侧设置。

打开本地 `index.html` 即可使用。所有数据仅在当前浏览器中处理，不会上传到服务器。右上方工具栏中的问号打开完整说明书。复购率和清洗入口位于左侧可展开的补充设置。

先上传源文件，核对统计日期和渠道，再填写目标及重点商品，点击生成。修改配置后需要重新生成。重点商品留空展示全部；完整明细的排名基于清洗后的全部商品。子公司表按所选渠道销量占比降序排列。

汇总文件缺少区域、渠道或金额时采用简化报表。源文件中的实收、毛利、同期指标不加入输出。日期只从源文件统计信息自动读取，不把下载文件名视为统计日期。

配置可保存在当前浏览器；源文件、复购文件及清洗名单需在刷新后重新加载。页面内说明书介绍公式、格式和排错方式。

## 验证

运行 `node tests/regression.cjs` 检查日期、字段兼容、渠道合并、目标零值、清洗占比及语法。浏览器布局、剪贴板权限和 WPS 打开效果需要在相应应用中验证。

## 更新方式

商品名称在源数据、重点商品、清洗名单和复购文件中统一剔除反引号（`），剔除后精确匹配；预览、总结、复制和导出的商品名均不带反引号。同名数据合并统计。

运行 `bash 发布.command --check` 检查本地版本；运行 `bash 发布.command` 发布到本报表仓库并等待 GitHub Pages 完整文件 SHA256 匹配；`bash 发布.command --verify` 仅检查线上版本。发布入口复用相邻测算工具已有的官方 GitHub CLI 和登录配置，不修改测算工具、其发布仓库或凭据。详细使用方式见 `发布说明.md`。

本地修改保存后刷新页面。只有推送到远程并完成 Pages 部署，在线地址才会更新；本地提交不会自动发布。
